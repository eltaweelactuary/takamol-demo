# Takamol — Offline Judge Demo

`index.html` هو الديمو الفعلي: نسخة عربية RTL تعمل من الجهاز مباشرة، ولا تحتاج إلى Node.js أو Python أو Firebase أو قاعدة بيانات أو إنترنت. صُممت لعرض الفكرة أمام لجنة خلال 2–3 دقائق مع بيانات تركيبية وحالة محلية محفوظة في المتصفح.

## التشغيل المحلي (الأسهل)

1. افتح `e:\New folder (3)\takamol_mvp\index.html` بالنقر المزدوج.
2. استخدم Edge أو Chrome حديثًا.
3. اضغط **«ابدأ جولة المحكّم»** واتبع المراحل التسع.
4. اضغط **«إعادة ضبط الديمو»** قبل دخول لجنة جديدة.

لا يُرسل الديمو شيئًا عبر الشبكة. إذا منع المتصفح `localStorage` عند فتح ملف محلي، يستمر الديمو في الذاكرة حتى إغلاق التبويب. بديل اختياري عند حدوث ذلك: شغّل يدويًا من Terminal داخل هذا المجلد:

```powershell
py -m http.server 8080
```

ثم افتح `http://localhost:8080`. أوقف الأمر بعد العرض بـ`Ctrl+C`.

## ما الذي يعمل فعلًا في الديمو؟

- رحلة من 9 مراحل: المشكلة → الموافقة → مزامنة محلية تجريبية → جودة 17 مؤشرًا → مؤشر خطر شفاف → تفسير وMoveDiscount افتراضي → مراجعة بشرية → حدود البحث → مسار الطيار والإيراد.
- الأزرار تغيّر الحالة، وتحسب نتيجة نموذج ديمو حتمي، وتسجل أحداثًا في سجل تدقيق محلي.
- إمكانية اختيار حالتين تركيبيتين بالعمر نفسه مع مدخلات مختلفة، وسحب الموافقة، وتسجيل مراجعة بشرية مع سبب تجاوز إلزامي.
- محفظة من 120 سجلًا تركيبيًا حتميًا للشرح فقط.
- حاسبة إيراد قابلة للتعديل: اشتراك مؤسسي + رسوم وثيقة/API + تهيئة أولية.

## ما الذي لا يدعيه؟

- لا عملاء حقيقيون، ولا إيراد محقق، ولا تجربة تجارية أو موافقة FRA.
- لا اتصال حقيقي بـApple Health أو Health Connect أو جهاز قابل للارتداء.
- لا بيانات شخصية أو صحية حقيقية، ولا تسجيل دخول، ولا قاعدة بيانات.
- لا تشغيل لـDeepSurv. محرك الديمو هو `DemoRiskModel` تركيبي شفاف فقط.
- لا نتيجة طبية، أو احتمال مطالبة، أو تسعير، أو إجراء سلبي تلقائي.
- أرقام `0.781 / 0.712 / 0.221 → 0.332` تظهر فقط كـ**نتائج بحث/محاكاة وليست جذبًا تجاريًا**؛ لم تُعد محليًا لغياب artifacts والبيانات اللازمة.

## النشر المجاني على GitHub Pages (اختياري)

> لا تحتاج Firebase لهذا الديمو. GitHub Pages أنسب لأنه يستضيف ملفات HTML/CSS/JS الثابتة مجانًا. لا ترفع أي بيانات أو أسرار أو ملفات عميل. إذا اخترت مستودعًا عامًا، فكل ما فيه سيكون عامًا.

1. أنشئ مستودع GitHub جديدًا، مثل `takamol-demo`.
2. ارفع **هذه الملفات فقط** إلى جذر المستودع: `index.html` و`styles.css` و`app.js` و`README.md` و`DEMO_SCRIPT.md` و`.nojekyll`.
3. من GitHub: **Settings → Pages → Build and deployment → Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/(root)` ثم **Save**.
5. بعد النشر افتح رابط Pages الظاهر في الشاشة، مثل `https://<account>.github.io/takamol-demo/`.

لا أنشر المشروع أو أنشئ مستودعًا من جانبي من دون موافقة صريحة منك، لأن ذلك يرفع الكود إلى خدمة خارجية. التحقق المحلي أكد وجود GitHub CLI مصادق عليه في الجهاز؛ لم نستخدمه للنشر.

## أقل بنية تطوير للمرحلة التالية

1. **شريك تصميم واحد** من شركة حياة أو صحي.
2. **وضع ظل**: لا يتغير سعر أو قرار؛ تُقاس جودة البيانات والاستخدام والتفسير.
3. **معايرة محلية وعدالة** مع بيانات مصرح بها وإشراف قانوني/اكتواري.
4. **قرار تجاري واضح**: استمر، عدّل، أو توقف.
5. عند وجود ذلك فقط: Backend، هوية مؤسسية، قاعدة بيانات، وتكامل أجهزة حقيقية.

| الملف | الغرض |
|---|---|
